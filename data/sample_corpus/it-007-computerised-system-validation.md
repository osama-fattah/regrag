# IT-007 Computerised System Validation

Northwind Biologics (fictional company). Synthetic SOP written for the RegRAG demo corpus.

## Approach

Northwind validates GxP computerised systems using a risk-based approach aligned with GAMP 5. The validation effort is proportionate to the system's impact on patient safety, product quality and data integrity.

## Software categories

Systems are classified using GAMP software categories. Category 1 covers infrastructure software such as operating systems. Category 3 covers non-configured products used as supplied. Category 4 covers configured products, such as a laboratory information management system configured to Northwind workflows. Category 5 covers custom or bespoke applications and requires the most rigorous lifecycle controls, including code review.

## Validation deliverables

A validation plan, user requirements specification, risk assessment, test scripts and a validation summary report are required for every GxP system. Category 4 and 5 systems also require a configuration or design specification and a traceability matrix linking requirements to tests.

## Periodic review

Validated systems undergo periodic review to confirm they remain in a validated state. High-risk systems are reviewed every year and medium-risk systems every two years. The review covers change history, incidents, audit trail findings, user access and supplier status.

## AI and machine learning components

Systems that include a machine learning model must document the training data source, the intended use, performance acceptance criteria and a monitoring plan for model drift. A model retrained on new data is treated as a change and goes through change control before release.
